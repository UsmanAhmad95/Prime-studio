## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/prime-studio.git
cd prime-studio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Development Server
```bash
npm run dev
```
The application will run locally on `http://localhost:3000`.

### 4. Production Build
```bash
npm run build
```
Compiled static assets will be output to the `/dist` directory.

### 5. Local Production Preview
```bash
npm run preview
```

## 🌐 Deploying to Vercel

1. Push your repository to **GitHub**.
2. Go to [Vercel](https://vercel.com/) and click **"Add New Project"**.
3. Import your `prime-studio` repository.
4. Vercel will automatically detect **Vite**:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
5. Click **Deploy**. The project includes a configured `vercel.json` for SPA deep-link routing and immutable asset caching.
